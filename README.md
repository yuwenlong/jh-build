## 🚀 为什么选择 Go 版江湖？

### ASP 版的三大死穴

> 你是否也遇到过这些令人崩溃的问题？

❌ **卡死宕机**：50人同时在线就开始卡顿，100人直接宕机，让玩家骂你  
❌ **运维噩梦**：必须 Windows Server + IIS + ASP 环境，一旦主机到期迁移服务器就要配置半天  
❌ **聊天延迟**：ASP版靠页面3秒刷新来"模拟"实时聊天，玩家发完消息等半天才看到  
❌ **安全漏洞**：Access数据库、无加密、SQL注入漏洞，随时被黑客洗库  
❌ **时代淘汰**：微软早就宣布 ASP/IIS 为传统技术，越来越多主机商停止支持

### Go 版的颠覆性优势

✅ **真·实时通信**：WebSocket 长连接，消息毫秒级到达，聊天体验媲美微信  
✅ **扛住高并发**：Go 协程天生为并发而生，同等服务器**承载人数是 ASP 版的 10 倍以上**  
✅ **单文件部署**：一个可执行文件 + 配置文件，Windows/Linux/ARM 全平台运行，5分钟上线  
✅ **银行级安全**：bcrypt 密码加密、Session 加密、全参数化查询，零 SQL 注入风险  
✅ **系统设置持久化**：后台修改站点名称、域名、游戏参数等，**立即生效、重启不丢失**（DB 持久化）  
✅ **市面唯一**：**全网唯一 Go 版江湖**，独家技术，买了就是竞争壁垒

> ⚠️ **本程序为商业软件，仅提供编译后的可执行文件，不提供源代码。**

## ⚡ 与ASP版性能对比（碾压级）

### 🔬 响应速度对比（同等硬件 · 50并发用户）

| 操作           | ASP 版耗时         | Go 版耗时             |    性能提升     |
| -------------- | ------------------ | --------------------- | :-------------: |
| 登录请求       | ~800ms             | ~5ms                  | 🚀 **快160倍**  |

## 🚀 运维部署指南

### 📦 交付内容

购买后您将收到一个压缩包，解压即用，包含：

- **主程序**：`jh-windows-amd64.exe` / `jh-windows-arm64.exe`（Windows）/ `jh-linux-amd64` / `jh-linux-arm64`（Linux），单文件，**无需安装任何运行时**，根据您的服务器架构选择对应文件即可
- **配置文件**：`conf/config.toml`，支持热更新，修改后自动生效
- **数据库**：`data/jh.db`，首次运行自动创建，SQLite 单文件，备份方便
- **界面文件**：`templates/`（HTML 页面）、`static/`（CSS/JS/图片），可自行修改界面风格；其中 CSS/JS/图片修改后刷新浏览器即可生效，修改 HTML 模板后需重启服务
- **功能使用文档**

### 快速启动（5分钟上线）

**打包结果目录结构：**

```
bin/
├── jh-windows-amd64.exe   # Windows x64（Intel/AMD）
├── jh-windows-arm64.exe   # Windows ARM64（如 Surface Pro X）
├── jh-linux-amd64         # Linux x64（主流 VPS，推荐）
├── jh-linux-arm64         # Linux ARM64（ARM 云服务器/树莓派）
├── templates/             # HTML 模板（可自定义界面）
├── static/                # CSS / JS / 图片
├── conf/                  # 配置文件
├── data/                  # 数据库（首次启动自动创建）
└── logs/                  # 运行日志
```

**Windows：**

```powershell
# 直接双击 jh-windows-amd64.exe，或命令行运行：
.\jh-windows-amd64.exe

# 推荐：NSSM 注册为 Windows 服务（开机自启，后台运行）
nssm install JiangHu "C:\path\to\bin\jh-windows-amd64.exe"
nssm set JiangHu AppDirectory "C:\path\to\bin"
nssm start JiangHu
```

**Linux（推荐，性能更强）：**

```bash
chmod +x ./jh-linux-amd64
nohup ./jh-linux-amd64 > logs/run.log 2>&1 &
```

**systemd 服务（Linux 推荐，自动重启）：**

```ini
[Unit]
Description=江湖聊天室
After=network.target

[Service]
WorkingDirectory=/opt/jh
ExecStart=/opt/jh/jh-linux-amd64
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

### 🌐 Nginx 反向代理（强烈推荐）

```nginx
server {
    listen 80;
    server_name 你的域名.com;

    # gzip 压缩（减少 60-80% 带宽）
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;
    gzip_min_length 1024;

    # 静态资源缓存（减少重复传输）
    location /static/ {
        proxy_pass http://127.0.0.1:8080;
        expires 1d;
        add_header Cache-Control "public, max-age=86400";
    }

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";  # WebSocket 关键配置
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

> 💡 **gzip 压缩和静态资源缓存均在 Nginx 层处理**，程序本身不重复处理，性能最优。

### 🔒 安全建议

1. **立即修改管理员密码**（首次启动后第一件事）

## 💻 服务器配置推荐

### 🧮 技术说明

Go 版每个 WebSocket 连接仅消耗约 **20-50KB 内存**，每次数据库查询约 **0.5-2ms**。消息广播采用**房间索引**，仅向目标房间内的连接推送，CPU 不随总在线人数线性增长。得益于 Go 的协程模型，**千人并发对服务器几乎没有压力**。

**高性能架构设计（开箱即用）：**

| 特性 | 说明 |
|------|------|
| 广播消息预序列化 | 同一条消息只序列化一次，N 个连接共享同一份数据 |
| WebSocket 批量写入 | 消息合并发送，减少系统调用 |
| Session O(1) 查找 | 反向索引，万人在线认证性能不衰减 |
| NPC 数据内存缓存 | 热数据常驻内存，无重复数据库查询 |
| 自动内存回收 | 过期缓存定时清理，长期运行内存稳定 |
| WebSocket 消息限流 | 防止恶意客户端耗尽服务端资源 |
| pprof 性能监控 | 管理员可随时分析 CPU/内存状况 |

## ❓ 常见问题

**Q：访问时出现 403 Forbidden 是什么原因？**

> 您购买的版本已绑定授权访问地址（域名或 IP + 端口）。请确认访问的地址与购买时登记的授权地址完全一致：
> - 若使用 **域名 + 80 端口**，请确认 Nginx/反代已正确转发，且未绑定其他域名
> - 若使用 **IP + 端口**，请确认与购买时填写的 IP 一致
>
> 若确需更换绑定地址，请联系原作者重新编译授权版本。

**Q：启动后提示端口被占用？**

> 修改 `conf/config.toml` 的 `server.port` 换个端口，或停止占用该端口的程序。

**Q：忘记管理员密码？**

> 联系技术支持（原作者）重置密码。

**Q：如何定期备份数据库？**

> ```bash
> # Linux（加入 crontab，每天凌晨3点自动备份）
> 0 3 * * * cp /opt/jh/data/jh.db /backup/jh_$(date +\%Y\%m\%d).db
> ```
>
> ```powershell
> # Windows 计划任务
> schtasks /create /tn "JH-Backup" /tr "copy C:\jh\data\jh.db C:\backup\jh_%date:~0,4%%date:~5,2%%date:~8,2%.db" /sc daily /st 03:00
> ```

**Q：如何自定义界面风格？**

> 修改 `templates/` 下的 HTML 文件需重启服务生效；修改 `static/` 下的 CSS/JS/图片，刷新浏览器即可生效。

**Q：支持 HTTPS 吗？**

> 程序本身走 HTTP，前面加 Nginx 配 SSL 证书即可实现 HTTPS。WebSocket 自动升级为 WSS。

**Q：能同时开多个江湖？**

> 可以。每个实例用不同端口和不同数据库路径，互不影响。

**Q：Linux 和 Windows 哪个性能更好？**

> Linux 更推荐。Go 程序在 Linux 上调度效率更高，同配置下 Linux 能多承载约 20% 的并发用户。
